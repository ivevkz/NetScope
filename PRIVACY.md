# Политика конфиденциальности NetScope

23 ноября 2026 г. · Автор: ivevkz

NetScope — бесплатная программа. Для работы не требуется аккаунт. История сетевой активности хранится на компьютере. NetScope не передаёт её автору и не использует рекламную аналитику.

## Что хранится на компьютере

В папке %LOCALAPPDATA%\NetScope сохраняются настройки, история трафика и отчёты. В зависимости от включённых функций они содержат имена и пути программ, объёмы трафика, время соединений, адреса и порты, имена хостов из DNS-кэша, сведения об устройствах сети и события безопасности. При включении контроля Wi-Fi могут обрабатываться идентификаторы точки доступа. Страны IP-адресов определяются по базе внутри приложения.

Установленная служба временно хранит замеры трафика в защищённой папке ServiceData внутри каталога установки. Приложение переносит их в историю и подтверждает получение. Буфер ограничен последними 24 часами и 64 МБ.

## Когда данные покидают компьютер

• Обновления. При ручной или автоматической проверке NetScope обращается к GitHub Releases. GitHub и его сеть доставки получают обычные данные запроса, включая IP-адрес. Автообновления можно выключить в разделе «О программе».

• Проверка файлов. По вашему запросу NetScope отправляет VirusTotal хеш SHA-256 файла и, для запроса через API, ваш ключ. Содержимое файла NetScope туда не загружает. Ключ хранится зашифрованным средствами Windows для текущего пользователя. Его можно удалить в настройках проверки файлов. Проверка Microsoft Defender использует настройки защиты Windows, включая выбранные вами облачные функции.

• Проверка скорости. Выбранные серверы, например Cloudflare или серверы LibreSpeed, видят IP-адрес и обмениваются с NetScope тестовыми данными. Для подбора ближайших серверов используется регион Windows.

• Списки угроз и поиск устройств. При включённой проверке Feodo Tracker загружается список адресов, который сравнивается с соединениями на компьютере. Поиск устройств обменивается запросами с узлами выбранной локальной сети.

• Экспорт и удалённый просмотр. При экспорте вы выбираете место для отчёта. При включении передачи снимка в выбранную папку записываются имя компьютера, график, соединения и последние события. Доступ к этим файлам определяется правами папки. По вашему выбору события также записываются в журнал Windows.

## Управление историей и связь

Срок хранения подробной истории задаётся в общих настройках. Месячные отчёты сохраняются отдельно. Для удаления локальной базы и настроек завершите NetScope через трей и удалите папку %LOCALAPPDATA%\NetScope. Экспортированные отчёты, общие снимки, системный журнал и правила брандмауэра управляются отдельно.

Вопросы автору можно задать через https://github.com/ivevkz/NetScope/issues. Обращения там публичны. Перед публикацией удалите из вложений ключи, пути и сетевые адреса, которыми не хотите делиться.
